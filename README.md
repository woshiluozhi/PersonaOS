# PersonaOS

PersonaOS is a local-first iOS SwiftUI MVP for a personal companion system inspired by a strict long-term mentor. It uses SwiftData, a deterministic local `MockAIClient` fallback, and an optional OpenAI Responses API client with structured JSON outputs configured from the in-app settings screen. API keys are stored only in iOS Keychain.

- Memory system with add, duplicate detection, empty-content guards, blank-record filtering, clean candidate/saved/confirmed/display/search content and source metadata, default source fallback, canonical tag parsing, multi-term status/date/relative date/clamped weight-aware search, confirm, ignore, restore, service-generated delete confirmation copy, tag chips, shared clamped responsive weight metrics, service-derived status summaries, status filters, and dismissed-memory cleanup.
- Daily review with same-day upsert, today status, date-scoped completion explanations, clean report text display/search with searchable blank-summary fallback, multi-term report search across text/date/relative date/XP/completion rate, shared clamped report metrics and model-derived completion/XP/percent labels for rows/search/summaries/trends/day bars, service-generated delete confirmation copy, stable date-first report ordering and related report lookup, latest-per-day responsive 7-day trend metrics with clamped display rates, completion rate, XP, best day, current streak, best streak, and local insights.

## Run

1. Open `PersonaOS.xcodeproj` in Xcode.
2. Select the `PersonaOS` scheme.
3. Select an available iPhone simulator, for example `iPhone 17`.
4. Run the app.

First launch seeds local demo data, including yesterday's sample report so today's review can still be generated by the user.

```sh

  -scheme PersonaOS \
  -destination 'platform=iOS Simulator,name=iPhone 17' \
  -derivedDataPath ./DerivedData \

```

```sh
xcodebuild \
  -scheme PersonaOS \
  -destination 'platform=iOS Simulator,name=iPhone 17' \
  -derivedDataPath ./DerivedData \
  build-for-testing
```

Recent successful logs are recorded in `CODEX_REPORT.md`. Full XCTest execution may stall in this local iOS 26.5 simulator environment during simulator diagnostics; `build-for-testing` is currently the reliable verification path for test bundle compilation.

## Notes

- All app data is local SwiftData.
- Without an OpenAI API Key, the assistant uses deterministic local mode.
- With an OpenAI API Key saved in Settings, chat sends only the current user message and essential context to OpenAI: profile names, current main quest/task state, recent confirmed memories, and recent review summaries.
- PersonaOS does not send full local chat history or use OpenAI conversation state for follow-up requests.
- The assistant can suggest memories and tasks, but the user must confirm before anything is written to local data.
