Support for the PersonaOS iOS app.

Contact

For app issues, general feedback, feature requests, or privacy questions, open a public issue on GitHub:

https://github.com/woshiluozhi/PersonaOS/issues

Before You Send Sensitive Information

Do not include OpenAI API Keys, private memories, private task details, personal notes, or other sensitive information in public GitHub issues. If a private support channel is added later, this page should be updated before the App Store submission.

App Data Controls

PersonaOS stores productivity data locally by default. In Settings, you can export local SwiftData content as JSON, clear chat, clear memories, clear daily reviews, reset demo data, and delete the stored OpenAI API Key from Keychain.
