PersonaOS Accessibility

Accessibility information for the PersonaOS iOS app.

PersonaOS is built with SwiftUI and standard iOS controls where possible. The app uses adaptive system colors for light and dark appearances and includes accessible labels on many icon-only controls.

Features Being Evaluated

Before publishing Accessibility Nutrition Label support claims, PersonaOS will evaluate common app tasks with VoiceOver, Voice Control, Larger Text, Dark Interface, Differentiate Without Color Alone, Sufficient Contrast, and Reduced Motion.

Media Accessibility

PersonaOS does not include video or audio dialog content, so captions and audio descriptions are not applicable to the current app experience.

Known Scope

Accessibility support statements should be based on the final signed build and real-device testing. If you encounter an accessibility issue, report it through the support page.
