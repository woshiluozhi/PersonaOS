# PersonaOS Real AI Text Interaction

This note describes the real text interaction path implemented in PersonaOS.

## What Is Implemented

- The chat surface keeps `AIClientProtocol` as the app-facing interface.
- `MockAIClient` remains the deterministic local fallback.
- `OpenAIClient` calls `POST https://api.openai.com/v1/responses`.
- The default model is fixed to `gpt-5.2` for this first version.
- API keys are saved only in iOS Keychain through `KeychainAPIKeyStore`.
- The Settings screen provides API Key save, delete, and connection test controls.
- The chat screen shows a loading state, supports cancellation, and saves chat messages locally.
- OpenAI replies are parsed into the internal `AIResponse` shape:
  - `assistantMessage`
  - `suggestedMemories`
  - `suggestedTasks`
  - `riskFlags`
- Suggested memories and tasks are never written automatically. The user must tap to save them.

## How To Try It On iPhone

1. Run PersonaOS on the iPhone.
2. Open `首页`.
3. Tap the gear button to open `设置`.
4. In `AI 模式`, paste an OpenAI API Key.
5. Tap `保存 Key`.
6. Tap `测试连接`.
7. Go to `对话`.
8. Send `我该做什么`, `检查风险`, `总结今天`, or `我想开新项目`.

If the key works, the reply is generated by OpenAI. If the key is missing, invalid, the network is unavailable, or parsing fails, the chat automatically falls back to local mode and the assistant message starts with `本地模式`.

## Context Boundary

PersonaOS does not replay the full chat history to OpenAI. Each request sends only the current user message and a bounded state snapshot:

- User name, companion name, user level, and current XP.
- Current active quest title: at most 1 item.
- Today task titles: at most 12 cleaned titles.
- Completed-today task titles: at most 12 cleaned titles.
- Overdue task titles: at most 8 cleaned titles.
- Recent confirmed memories: at most 5 cleaned memories.
- Recent daily review summaries: at most 3 cleaned summaries.

PersonaOS does not connect to Contacts, Calendar, Health, location, microphone recording, background collection, or other apps.

## Fallback Behavior

`AIClientFactory` chooses the runtime client:

- No saved API Key: `LocalModeAIClient(MockAIClient)`.
- Saved API Key: `FallbackAIClient(OpenAIClient, MockAIClient)`.

Fallback is used for missing keys, HTTP failures such as `401`, network failures, invalid JSON, and invalid structured output. Fallback replies are visibly marked with `本地模式`.

## Verification

Build for testing:

```sh
xcodebuild \
  -scheme PersonaOS \
  -destination 'platform=iOS Simulator,name=iPhone 17' \
  -derivedDataPath ./DerivedData \
  build-for-testing
```

Run tests without rebuilding:

```sh
xcodebuild \
  test-without-building \
  -scheme PersonaOS \
  -destination 'platform=iOS Simulator,name=iPhone 17' \
  -derivedDataPath ./DerivedData
```

Static readiness gate:

```sh
scripts/verify_app_store_readiness.sh
```
